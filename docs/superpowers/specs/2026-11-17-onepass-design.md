# 공동현관 버튼

사용자 승인 범위: 출입문 목록 조회와 HA 출입문별 공동현관 열기 버튼.
기존 cloud 2.0 세션과 button 플랫폼을 확장한다. 별도 통합이나 lock 엔티티는
중복 설정 또는 확인할 수 없는 잠금 상태를 요구하므로 사용하지 않는다.
시작 시 onepass 지원을 확인하고 GET /v2/api/onepass/doors의 id/lobby_name으로
버튼을 만든다. 지원 정보가 불명확하면 목록 조회만 시도하며, 실패해도 기존
장치 초기화를 막지 않는다. 목록 갱신은 통합 다시 불러오기로 한다.
버튼은 POST /v2/api/onepass/doors/{id}/apply에 공식 앱의 appname과
현재 로그인 세션 alias를 보낸다. 자동 재시도하지 않으며 성공은 요청 접수만
뜻한다. 실제 잠금 상태는 제공하지 않는다. 실서버 개방, HA 배포는 범위 밖이다.
안정적인 문 ID, 안전한 경로 인코딩, 잘못된 응답 및 누락 alias 처리,
기존 엘리베이터 유지와 오류 표시를 오프라인 테스트한다.
